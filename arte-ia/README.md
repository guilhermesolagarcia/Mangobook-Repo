# arte-ia/

O que **a gente gerou com IA** pra Mango. É material nosso: pode ser usado no site e nas pranchas.

| Pasta | O que tem |
|:--|:--|
| `mangy/` | O mascote: `mangy-final.png` (oficial) e as folhas de expressões, cores, olhos, ícone, selo, maturação e produto. `scripts/recortar-mascote.py` recorta essas folhas pra `design/marca/mascote/`. Em `historico/`, as versões anteriores (v1, v2). |
| `adesivos/` | Adesivos prontos. O `batmango.png` é o padrão aprovado pros próximos. |
| `prompts/` | Os prompts usados: `adesivos.md` (todos os adesivos e o padrão Batmango) e as ideias de imagem de abertura. |
| `referencias/` | Imagens que a gente anexa nos prompts (ex.: o logo). |
