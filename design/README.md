# design/

Tudo o que foi decidido **antes** do código. Abre no navegador com `npm run dev` em `localhost:5173/design/`.

| Pasta | O que tem |
|:--|:--|
| `marca/` | O kit da marca: prancha, logo, Mangy, apps, cartões-presente e adesivos (rascunho). Cada prancha troca de tema com `?v=uva`, `?v=noite`… |
| `prototipos/` | Os protótipos aprovados, em HTML de um arquivo só: `pure.html` (virou o site em React) e `loja.html` (a Mango Store, próxima a ir pro React). |
| `escolhas/` | Cada decisão de design com as opções lado a lado: abertura, navbar, troca de cor, ícones, imagem do "Amor à primeira fruta". |
